## 2025-01-08 - Optimize Mongoose Queries
**Learning:** Avoid using `Model.findById(id)` just to check if a document exists, as it fetches the entire document into memory, wasting resources. Also, for endpoints that update an existing document, using `Model.findOne()` followed by `model.save()` executes two database roundtrips, slowing down performance. Finally, failing to use `.lean()` on read-only queries causes Mongoose to build heavy document wrappers unnecessarily.
**Action:** Always use `Model.exists({ _id: id })` for simple existence checks. Refactor `findOne()` + `save()` patterns into a single `Model.findOneAndUpdate(...)` with the `{ new: true }` option. Always append `.lean()` to Mongoose queries when the data is purely for read operations and does not need to be saved back or use Mongoose-specific methods.
