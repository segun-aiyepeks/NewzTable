## 2024-11-05 - Avoid Mongoose overhead
**Learning:** Found several places where Mongoose documents were instantiated (missing `.lean()`) even when the documents were not modified but simply returned to the client, leading to unnecessary memory usage and processing. Also, some document updates used a separate `findOne` and `save` when a single `findOneAndUpdate()` would have sufficed. Furthermore, `findById` was used instead of `exists()` just to check if a document exists, creating unnecessary object overhead.
**Action:** Always append `.lean()` to Mongoose queries when the resulting documents are read-only (not saved back via `.save()`). When updating documents, combine separate fetch-and-save operations into single `findOneAndUpdate().lean()` updates. For existence checks, prefer `.exists()` over full queries.
